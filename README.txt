YASMIIN FOUNDATION WEBSITE
===========================
Files:
- index.html
- style.css
- script.js
- assets/ (the four photos supplied in the chat)

How to use:
1. Keep the folder structure unchanged.
2. Open index.html in Chrome/Edge/Firefox.
3. For online hosting, upload the whole folder to your web host.

Notes:
